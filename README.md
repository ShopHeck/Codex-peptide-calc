Codex Peptide Calc

A peptide dosage and reconstitution calculator built with Codex.

Overview

Codex Peptide Calc helps researchers quickly calculate peptide concentrations, dosing amounts, and reconstitution values from common vial and dilution configurations.

The goal is to simplify peptide math, reduce manual calculation errors, and provide a fast, user-friendly workflow for research applications.

⸻

How It Works

Given:

* Peptide amount in a vial (mg)
* Diluent volume (mL)
* Desired dosage (mcg or mg)

The calculator determines:

* Concentration per mL
* Dosage volume required
* Syringe unit equivalents (when applicable)
* Number of doses per vial

Example

Vial: 5mg

Diluent: 2mL BAC Water

Desired Dose: 250mcg

Results:

* Concentration: 2500mcg/mL
* Dose Volume: 0.1mL
* U-100 Syringe Units: 10 units
* Approximate Doses Per Vial: 20

Installation

Clone the repository:

git clone https://github.com/ShopHeck/Codex-peptide-calc.git

Navigate into the project:

cd Codex-peptide-calc

Install dependencies:

npm install

Start the development server:

npm run dev

Build for production:

npm run build
